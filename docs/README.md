# TaskMyScreen Engineering Framework

This directory contains the approved TaskMyScreen product, architecture, AI-governance, development, QA and production-readiness documentation.

## Authority order

1. Master Project Charter
2. Product / Business documentation
3. Architecture documentation
4. Development Implementation Protocol
5. QA documentation
6. Source code

`GEMINI.md` is the operational entry point for Gemini Code Assist and instructs Gemini to load the applicable authoritative documents before modifying the codebase.

## Document set

The framework contains 15 authoritative documents covering Governance, Product, Architecture, Backend, Frontend, AI governance, Development, QA and Operations.
